# Docs Layout

- `AGENTS.md` — entry point và repo rules cho coding agents.
- `CONTEXT.md` — ubiquitous language, current state và durable principles.
- `docs/prd/` — product requirements.
- `docs/issues/` — local implementation tickets.
- `docs/adr/` — accepted architecture decisions.
- `docs/architecture/` — mô tả kiến trúc hiện hành.
- `docs/conventions/` — coding/module/document conventions.
- `docs/integrations/` — hướng dẫn tích hợp từ góc nhìn consumer/operator.
- `docs/testing/` — acceptance và verification guidance.
- `docs/agents/` — workflow, skill và cấu hình dành cho agent.
- `docs/agents/skills/mattpocock/` — workflow skills được vendor cùng references/templates.
- `docs/agents/skills/ui-ux-pro-max/` — UI/UX design intelligence, search data và platform skills.

Không đưa kế hoạch tạm thời vào ADR. Không mô tả tính năng chưa triển khai trong architecture
docs như thể nó đã tồn tại.
